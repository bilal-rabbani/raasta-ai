# RAASTA AI

RAASTA AI (Regulatory Assistance & Step-by-Step Task Assistant) is an AI-powered government procedure navigator for Pakistan.

## Current Version

Part 1 - Basic RAASTA interface

## Goal

Tell RAASTA AI what you want to accomplish and receive guidance on the next steps.

## Development

The project will be developed incrementally, adding:

- Government scope detection
- RAG
- Government source verification
- Personalized questions
- Requirement analysis
- Multi-agent architecture
- Roadmaps
- Progress tracking
- English and Urdu support
